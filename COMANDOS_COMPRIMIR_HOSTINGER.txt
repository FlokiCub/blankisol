================================================================================
  COMANDOS PARA PREPARAR Y COMPRIMIR EL PROYECTO LISTO PARA HOSTINGER
================================================================================

Este archivo contiene los comandos paso a paso para limpiar, optimizar y 
comprimir el proyecto en un archivo .ZIP listo para subir a Hostinger (hPanel).

--------------------------------------------------------------------------------
PASO 1: ABRIR LA TERMINAL EN LA RAÍZ DEL PROYECTO
--------------------------------------------------------------------------------
Abre PowerShell o Símbolo del Sistema (CMD) en la carpeta del proyecto:
  d:\XAMPP\htdocs\mi-web


--------------------------------------------------------------------------------
PASO 2: LIMPIEZA DE CACHÉ LOCAL Y PREPARACIÓN DE PRODUCCIÓN
--------------------------------------------------------------------------------
Ejecuta los siguientes comandos antes de comprimir para asegurarte de que 
no se empaqueten rutas ni configuraciones locales de XAMPP:

  # 1. Limpiar todas las cachés locales de Laravel
  php artisan optimize:clear
  php artisan config:clear
  php artisan route:clear
  php artisan view:clear

  # 2. Compilar assets de frontend (Tailwind / Vite) para producción (si tienes npm):
  npm run build

  # 3. Optimizar el autoloader de Composer sin librerías de desarrollo:
  composer install --no-dev --optimize-autoloader


--------------------------------------------------------------------------------
PASO 3: COMANDO PARA GENERAR EL ARCHIVO .ZIP
--------------------------------------------------------------------------------
Elige la opción que prefieras según la herramienta disponible en tu computadora:

--- OPCIÓN A: COMANDO UNIVERSAL DE WINDOWS (Nativo en Windows 10/11 - RECOMENDADO) ---
Ejecútalo tal cual en PowerShell o CMD (no necesitas instalar nada adicional):

tar -a -c -f deploy_hostinger2.zip --exclude=".git" --exclude="node_modules" --exclude="tests" --exclude="whatsapp-gateway" --exclude=".env" --exclude="*.zip" --exclude="scratch_*" --exclude="storage/logs/*.log" app bootstrap config database public resources routes storage vendor .htaccess .env.production.example artisan composer.json composer.lock


--- OPCIÓN B: SCRIPT DE POWERSHELL (Si prefieres un script PowerShell) ---
Copia y pega este bloque en PowerShell:

$exclude = @('.git', 'node_modules', 'tests', 'whatsapp-gateway', '.env', '*.zip', 'scratch_*', 'storage\logs\*.log')
$files = Get-ChildItem -Path . -Exclude $exclude | Where-Object { $_.Name -notin @('.git', 'node_modules', 'tests', 'whatsapp-gateway') }
Compress-Archive -Path $files -DestinationPath "deploy_hostinger.zip" -Force


--- OPCIÓN C: USANDO 7-ZIP (Si tienes 7-Zip instalado) ---
"C:\Program Files\7-Zip\7z.exe" a -tzip deploy_hostinger.zip . -xr!.git -xr!node_modules -xr!tests -xr!whatsapp-gateway -x!.env -x!*.zip -x!scratch_* -x!storage\logs\*.log


--------------------------------------------------------------------------------
PASO 4: SUBIR Y ACTIVAR EN HOSTINGER (hPanel)
--------------------------------------------------------------------------------
1. Entra a Hostinger -> "Sitios web" -> Tu dominio -> "Administrador de Archivos"
2. Entra a la carpeta "public_html"
3. Sube el archivo "deploy_hostinger.zip"
4. Clic derecho sobre "deploy_hostinger.zip" -> "Extraer" (Extract) en public_html
5. Renombra el archivo ".env.production.example" a ".env" y coloca tus credenciales
   de base de datos MySQL de Hostinger:
     APP_ENV=production
     APP_DEBUG=false
     APP_URL=https://tudominio.com
     DB_DATABASE=uXXXXXXX_nombre_bd
     DB_USERNAME=uXXXXXXX_usuario
     DB_PASSWORD=TuPasswordSeguro123!

6. Si tienes acceso SSH en Hostinger, ejecuta en la terminal de Hostinger:
     cd public_html
     php artisan migrate --force --seed
     php artisan storage:link
     php artisan optimize

   (Si no usas terminal, puedes importar la base de datos desde phpMyAdmin de Hostinger).

--------------------------------------------------------------------------------
RESUMEN DE QUÉ SE INCLUYE Y QUÉ SE EXCLUYE:
--------------------------------------------------------------------------------
  [+] INCLUIDO: app, bootstrap, config, database, public (con build compilado),
                resources, routes, storage, vendor (autoloader listo),
                .htaccess (redirección raíz segura), artisan, composer.json/.lock.
  [-] EXCLUIDO: .git, node_modules (ahorra cientos de MB), tests, whatsapp-gateway,
